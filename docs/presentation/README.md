# Final presentation

The presentation for the 10–15 minute project discussion is provided in two
formats:

- `energy_security_data_warehouse_presentation.pptx` — editable version;
- `energy_security_data_warehouse_presentation.pdf` — version for sharing and
  viewing.

The slides summarize the motivation, sources, Fact Constellation model, ETL
pipeline, data-quality controls, didactic OLAP session, analytical findings,
and conclusions. A short live demonstration can use the execution commands in
the repository root `README.md`.
